# Intelligence toolkit photography

Real airport photographs illustrate each tool. They are decorative reference
images, not current airport conditions, flight information or recommendations.

Photographs are bundled with the app; external image hosts are not used at runtime.
The downloaded source thumbnails are unmodified. CSS crops them for the cards.
