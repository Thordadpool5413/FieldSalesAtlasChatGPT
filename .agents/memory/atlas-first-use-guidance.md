---
name: Atlas first-use guidance
description: Keep first-visit orientation separate from the returning map and reuse the existing setup flow for resumption.
---

Keep first-use choices tied to the one-time Atlas welcome, and use the existing Workspace setup flow as the resumable guide. Do not leave the full first-use action chooser on every incomplete workspace.

**Why:** A persistent chooser pushed the map too far down on phones, while a separate onboarding preference would duplicate the existing workspace setup reminder state.

**How to apply:** Future orientation changes should link setup, map exploration, and travel to their existing routes; keep the full step-by-step setup available from Workspace setup, and keep repeat visits to the Atlas compact.
