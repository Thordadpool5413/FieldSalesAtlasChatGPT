---
name: Atlas visual language
description: Miami Vice palette roles, typography, and map color semantics for Field Sales Atlas.
---

For this app, cyan is for primary actions, live status, and keyboard focus; flamingo pink is for selected navigation and key accents; sunset peach is for the welcome hero and occasional highlights. Airport references retain their separate warm marker color. Keep map geography subdued and use distinct shapes and labels so marker meaning does not depend on color alone. Use Barlow Condensed for prominent display headings, DM Sans for readable body text, and reserve glow for active or focused elements.

**Why:** the user specified these visual roles so the Miami Vice theme stays recognizable without reducing operational map clarity.

**How to apply:** keep dark and light theme tokens aligned to the same semantic roles. Before changing map colors, check the legend and preserve the airport-reference encoding.
