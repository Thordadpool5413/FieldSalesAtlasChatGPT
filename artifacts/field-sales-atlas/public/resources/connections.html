Connect the services you choose.

The shared trip view and public evidence work without these accounts. Flight status and direct calendar updates need an authorized provider connection.

Put credentials in Replit Secrets, never in chat or source files. Development and published runtimes need their own intended settings. Restart one app instance after changing Secrets.

Flight-specific status

  1. Create an authorized FlightAware AeroAPI account. Review coverage, limits and pricing.
  2. Set ATLAS_AEROAPI_KEY in Secrets. Set ATLAS_AEROAPI_WORKSPACE_IDS to the approved workspace ID shown in My Trip’s provider setup details. This restricts paid usage to the intended workspace.
  3. To permit optional background checks, set ATLAS_FLIGHT_STATUS_POLLING=enabled. Then opt the trip into flight monitoring inside My Trip. Configure and verify the maintenance schedule.
  4. Attach reviewed operating-flight fields and run an exact-instance check. Confirmation numbers alone cannot retrieve reservations. Review any supplied change before recovery analysis.

Google and Outlook calendars

  1. Set ATLAS_PUBLIC_URL to your HTTPS app origin.
  2. Set ATLAS_CONNECTION_ENCRYPTION_KEY to 64 securely generated random hexadecimal characters. Retain it in a password manager; changing it requires reconnecting calendars.
  3. Register a Google OAuth web client with the Calendar API enabled. Set ATLAS_GOOGLE_CLIENT_ID and ATLAS_GOOGLE_CLIENT_SECRET. Add redirect URI https://field-sales-atlas.replit.app/api/travel/calendar/oauth/google/callback.
  4. Register a Microsoft Entra web app with delegated Calendars.ReadWrite permission and suitable account types. Set ATLAS_MICROSOFT_CLIENT_ID and ATLAS_MICROSOFT_CLIENT_SECRET. Add redirect URI https://field-sales-atlas.replit.app/api/travel/calendar/oauth/microsoft/callback.
  5. In My Trip, choose your own trainer seat, connect your primary calendar, and sign in with the provider. Each trainer authorizes separately. Review every proposed event before applying changes.

Atlas stores calendar tokens encrypted. It does not send invitations, delete external appointments, or automatically rebook flights. Existing exported events remain after disconnecting; revoke the grant in your provider account as well.

Background notifications

Use the current installed web app and enable notifications on your personal device. Opt the trip into monitoring, choose quiet hours if needed, and verify a delivered maintenance run. Updates remain in the app if push is unavailable. Notification payloads contain a generic prompt, with no itinerary or workspace access key.
